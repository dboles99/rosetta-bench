[S1] The `usefulness run` command runs the representation by decision matrix.
[S2] Pass `--reps M` to run only the machine view.
[S3] Without `--reps`, all three representations P, H and M run.
[S4] The default seed is 20261109.
[S5] Each generator call times out after 300 seconds unless you pass `--generator-timeout`.
[S6] Live runs must also set `--max-generator-calls`.
[S7] `--reps` accepts a comma-separated list such as `P,H`.
[S8] Without `--seed`, each run uses the default seed 20261109.
[S9] Passing `--reps P,H,M` is the same as the default.
