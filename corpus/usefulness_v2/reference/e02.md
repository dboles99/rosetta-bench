[S1] `parse_retry_after` reads the value of an HTTP Retry-After header.
[S2] It returns the wait time in seconds, as a float.
[S3] When the value is missing or not a number, `default` is used.
[S4] Negative values are clamped to 0.
[S5] Values above `cap` are clamped to `cap`.
[S6] Only the delay-seconds form is parsed; an HTTP-date counts as not a number, so `default` is used.
